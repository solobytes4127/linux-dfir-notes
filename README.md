# Linux DFIR Notes

Notes on Linux commands with a digital forensics angle. For every commands I write what it does, how it helps in a forensic investigation (DFIR use), and common works. Everything is practised hands-on in Kali Linux.

Status:work in progress, updated as I study.

# Contents
- `linuxcommands.md`: files and navigation, user accounts, permissions, and getting help (`man`, `apropos`, `whatis`)

# Why this repo
I'm building a foundation in digital forensics, starting with the Linux command line. These notes are my way of learning each command properly instead of just reading about it.

# Book and sources
- The Linux Command Line* by William Shotts (free at linuxcommand.org)
